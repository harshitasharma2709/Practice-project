Logistics & Delivery Management System

The Logistics & Delivery Management System is a web-based interface designed to manage shipment and delivery information in a simple and organized way.

The system provides different sections for managing shipments, customers, packages, delivery schedules and shipment tracking.

This frontend system provides a clear and responsive user interface and can be connected with a backend system in the next phase of development.
